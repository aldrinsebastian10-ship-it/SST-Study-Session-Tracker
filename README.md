# SST - Study Session Timer

SST (Study Session Timer) is a simple web app I made to keep track of my study sessions.

The idea is pretty straightforward: enter the subject you're studying, start the timer, and stop it when you're finished. The completed session is then added to the list with the subject and the amount of time studied.

## What it can do

- Add a subject before starting a session
- Start and stop a study timer
- Keep track of how long each session lasted
- Show completed sessions in a list
- Reset the timer after each session

## Built with

- HTML
- CSS
- JavaScript

I wanted to make something small and actually useful while learning the basics of JavaScript and web development. I'm also planning to keep improving the project as I learn more.
